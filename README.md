# Country Clean Cleaning Services 🌸

> **Clean Spaces, Happy Places.**  
> *“Let me do the cleaning, so you can enjoy what matters most!”*

A modern, responsive, animated, full-width website designed for **Country Clean Cleaning Services** — owned and operated with love & passion by **Ainslee Thompson** in **Ware County, Georgia**.

---

## ✨ Features

- **Edge-to-Edge Full-Width Design**: Modern, responsive layout with fluid spacing across mobile, tablet, and wide desktop screens.
- **Brand & Asset Integration**:
  - Official line-art wreath logo featured in the glassmorphic sticky header and footer.
  - Official rustic pink truck billboard & rate sheet showcased with an interactive click-to-zoom lightbox modal.
- **Interactive Instant Price Estimator**:
  - Live cost calculator reflecting the exact rates:
    - **Standard Home Cleaning**: $120 flat rate
    - **Deep Cleaning**: $180 flat rate
    - **Move-In / Move-Out Clean**: Up to $220 max
    - **RVs & Campers Detailing**: From $140 custom
  - Interactive bedroom/bathroom counters and add-on toggles (refrigerator, oven, windows, pet hair focus).
  - Pre-fills booking requests and generates one-click Facebook messages.
- **Interactive Before & After Slider**: Drag-to-reveal split comparison showing real cleaning transformations.
- **RVs & Campers Specialist Spotlight**: Dedicated section highlighting specialized travel trailer, motorhome, and camper detailing in South Georgia.
- **Local Georgia Coverage**: Interactive badges for Waycross, Manor, Millwood, Waresboro, Dixie Union, Blackshear / Pierce County, and surrounding areas.
- **Direct Communication Channels**: Instant links to the official [Facebook Page](https://www.facebook.com/country.cleaning.service.2026), phone calls, text messages, and a booking modal.
- **Delightful Micro-Animations**: Floating ambient bubbles and sparkles, smooth card elevations, and hover glows.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup with OpenGraph metadata.
- **CSS3**: CSS Custom Properties (variables), Flexbox, CSS Grid, Glassmorphism (`backdrop-filter`), Keyframe animations.
- **Vanilla JavaScript**: Zero dependencies, lightweight, high performance.
- **Typography**: Google Fonts (`Outfit`, `Plus Jakarta Sans`, `Alex Brush`).

## 🚀 Local Setup

No build tools or package managers required! Simply clone and open:

```bash
git clone https://github.com/jacobdesignixer-cmyk/country-clean-services.git
cd country-clean-services
```

Double click `index.html` or open it in any modern browser.
